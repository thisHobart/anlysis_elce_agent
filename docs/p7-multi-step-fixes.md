### 3. 改进实体提取正则表达式

**文件**: `app/graph/nodes/query_data.py:24`

**修改前**:

**修改后**:
```python
def _extract_entity_from_question(question: str, entity_type: str) -> str | None:
    """从问题中提取实体（简单正则匹配）"""
    if entity_type == "enterprise_name":
        patterns = [
            # 带后缀的完整企业名
            r"([一-龥]{2,20}(?:公司|集团|企业|工厂|工业园|发电站|新能源|能源|电力))",
            # 不带后缀但有常见企业关键词
            r"([一-龥]{3,20}(?=的|当前|实时|可调))",
            # 英文字母开头的企业名
            r"([A-Z]{2,}(?:公司|集团)?)",
        ]
        for pattern in patterns:
            match = re.search(pattern, question)
            if match:
                return match.group(1)
    return None
```

**改进点**:
1. **扩展长度限制**: 从 `{2,10}` 改为 `{2,20}`，支持更长的企业名
2. **添加更多后缀**: 增加 "新能源"、"能源"、"电力" 等常见企业后缀
3. **添加前瞻断言模式**: `r"([一-龥]{3,20}(?=的|当前|实时|可调))"` 可以匹配不带后缀但后面跟特定词的企业名
   - 例如: "山东鲁能新能源**的**实时负荷" → 提取 "山东鲁能新能源"
