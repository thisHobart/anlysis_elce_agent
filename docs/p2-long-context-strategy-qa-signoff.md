## 发现与处理

| # | 严重性 | 问题 | 处理 | 状态 |
|---:|---|---|---|---|
| 1 | MUST FIX | 早期 benchmark 将金标风险描述当作新闻标题，造成标签泄漏 | 改为中性样本编号标题，新增防泄漏测试，作废并重跑旧实时结果 | Fixed |
| 2 | MUST FIX | 旧 scorer 允许额外事件，可能把重复事件判为通过 | `strict-v2` 要求事件类型和状态多重集完全相等 | Fixed |
| 3 | MUST FIX | HTTP 500 被归为全局网关失败，导致整批测试中止 | 新增瞬时传输错误类型；单次失败隔离，全局配置/协议错误仍停止 | Fixed |
| 4 | MUST FIX | 结果只记录覆盖失败，未记录隔离原因 | benchmark 持久化主隔离和候选隔离 reason code | Fixed |
| 5 | SHOULD FIX | 当前网关没有可靠输出 token 和价格 usage | 报告标记不可用；列为生产前数据契约门禁 | Accepted for selection |
| 6 | SHOULD FIX | 真实模型只有 2 轮、语料为 10 个合成用例 | 限制结论为 MVP 选型；生产前要求真实新闻保留集 | Accepted for selection |
| 7 | MUST FIX BEFORE DEPLOYMENT | 本地 `llm_context_window_tokens=0`，测试显式使用 30,000 | 部署前必须为每个路由配置并核验正数窗口 | Deferred to deployment gate |
