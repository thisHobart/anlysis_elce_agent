# 电价研究 Agent

面向电价研究与预测的桌面工作台，支持通过自然语言完成数据分析、新闻研究和电价预测。Agent 负责理解问题、组织研究方案与解释结果，统计分析和预测由本地算法执行。

## 主要功能

- **电价与影响因素分析**：检查数据质量，分析电价分布、时序规律及其与外生变量的关系。
- **新闻研究**：导入新闻、提取与复核事件，分析新闻与电价的关联，为预测提供特征。
- **电价预测**：支持山东次日实时电价预测，输出回测结果与次日 96 点预测。
- **连续研究会话**：支持方案确认与修改、结果追问和历史会话保存。
- **研究报告**：生成包含结论、图表和方法说明的报告，便于查看与追溯。

基本流程：提出问题 → 确认方案 → 执行分析 → 查看报告与继续追问。

## 快速开始

需要 Python 3.11+。

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -e ".[dev]"
Copy-Item .env.example .env
.\venv\Scripts\python.exe -m app.desktop
```

启动前，在 `.env` 中填写模型服务商、接口地址、API Key 和模型名，也可通过桌面模型配置进行设置。支持 DeepSeek、Qwen、Gemini 原生 API 和自定义 OpenAI 兼容服务。

完成安装后，也可双击 `start_desktop.bat` 启动。

## 数据与使用

支持导入 CSV / Parquet 文件：目标电价为执行分析的必需数据，实际与预测外生变量为可选数据。也可通过地区数据源获取数据，当前启用山东数据源，数据库连接需在 `.env` 中配置。

导入数据后，在对话中描述研究问题，确认生成的方案即可执行。新闻研究支持本地工作台与冻结新闻快照；完整研究流程可衔接电价分析、新闻分析和预测，预测方案需单独确认。

## 技术与文档

桌面界面基于 PySide6，研究流程由 LangGraph 管理，数据分析使用 pandas、SciPy 和 statsmodels，预测使用 scikit-learn 与 PyTorch。研究方法通过 Skill 组织与扩展。

详细配置、架构、开发验证和阶段说明见 [项目文档](docs/README.md)。

Windows 打包可运行 `build_exe.bat`，添加 `--onefile` 可生成单文件版本。
