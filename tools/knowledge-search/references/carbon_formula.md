# 碳减排计算方法

## 基本原理

虚拟电厂的碳减排量通过替代传统火电出力来计算。当虚拟电厂通过新能源发电或负荷调节减少电网对火电的需求时，就产生了碳减排。

## 核心折算公式

```
碳减排量（吨CO₂）= 替代火电量（MWh） × 区域电网排放因子（tCO₂/MWh）
```

- **替代火电量** = 光伏实际发电量 + 储能放电量（从电网角度看相当于减少火电出力）
- **区域电网排放因子**：华北区域约 **0.833 tCO₂/MWh**（实际取值以生态环境部最新发布值为准）

## 等效植树换算

碳减排量常被换算为等效植树量作为公众沟通口径：

```
等效植树量（万棵） ≈ 碳减排量（吨） × 0.045
```

即约 **22 吨 CO₂ ≈ 1 万棵树**（植被年固碳量，取中等值）。

## 举例

若虚拟电厂一个月光伏发电 120 万度，储能放电 80 万度，总计替代火电 200 万度（2000 MWh）：

```
碳减排量 = 2000 MWh × 0.833 tCO₂/MWh = 1666 吨 CO₂
等效植树 = 1666 × 0.045 = 75 万棵
```

## 注意事项

- 排放因子取值因区域电网不同而有差异
- 光伏全生命周期碳排放极低，这里视为零碳
- 储能充电的电可能来自电网，其来源碳足迹在精细化计算时应考虑
- 实际碳交易中的减排量需经第三方核证
